# Prometheus v0.3 benchmark

These measurements precede Medium's native VM and Cff-protected helper changes.
See the [updated Medium report](v0.3-medium-native-cff.md) for the current preset.

Host: Linux-6.18.33.2-microsoft-standard-WSL2-x86_64-with-glibc2.44; CPU: 13th Gen Intel(R) Core(TM) i7-13850HX. Runtimes: Lua 5.1.5  Copyright (C) 1994-2012 Lua.org, PUC-Rio; LuaJIT 2.1.1792588164 -- Copyright (C) 2005-2026 Mike Pall. https://luajit.org/.

Four deterministic workloads compare original source with the actual presets, including AntiTamper. All variants must match the original checksum.

Seeds: [1, 4, 17]; 3 timed batches per seed. Each workload is parsed once and warmed up; batches adapt to approximately 0.1 seconds. Execution includes initialization of the emitted chunk, workload work, allocations, and checksum validation, but excludes parsing. Garbage collection runs before each batch; collection during the batch is included.

Execution figures are median CPU time per full invocation across batches and seeds. Generation and parsing figures are medians across seeds. Output size is a median across seeds. Execution ranges show the lowest and highest per-seed medians. Measurements are local, with JIT enabled for LuaJIT; very small native JIT times can produce large slowdown ratios. These workloads do not establish a general performance guarantee or measure peak memory.

## Observations

All 120 generated variants and 8 originals returned matching checksums on Lua
5.1 and LuaJIT. Each row contributes three timed batches. Production Medium and
Strong retained AntiTamper. One initial benchmark process exceeded 60 seconds
while repeating slow warmups; the runner was adjusted to warm up slow workloads
once before its three measured batches, then resumed the saved measurements.
The completed measurements stayed within the per-process limit.

Vmify is substantially slower than native Lua for these workloads, particularly
for numeric loops and closures. Strong adds a large further cost when Cff
flattens the interpreter. LuaJIT improves absolute execution times but does not
remove the VM overhead. These results warrant performance work before describing
v0.3 as highly performant; Strong is particularly costly on hot paths.

The per-seed ranges also show that performance varies with the pipeline seed.
Use both absolute times and ranges when choosing a preset. Generation was run
under Lua 5.1 for every variant; execution was measured separately under both
runtimes. Raw JSON and generated sources from this run are in
`/tmp/prometheus-v0.3-benchmark/`. To reproduce, run the command in
[README.md](README.md).
