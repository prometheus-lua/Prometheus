# PACA VM Refresh

이 프로젝트는 업로드된 PACA 소스를 바탕으로 기존 Prometheus 계열 사용자 정의 VM을 유지하면서 난독화 파이프라인과 웹 플레이그라운드의 신뢰성을 손본 버전입니다.

## 주요 변경

- 기존 `Vmify` 사용자 정의 바이트코드 VM을 그대로 사용합니다.
- Strong에서 중복 VM 컴파일을 제거했습니다.
- 문자열 분할, 문자열 암호화, 상수 배열화, 숫자 표현 변환을 VM 컴파일 전에 수행합니다.
- 브라우저에서 외부 Anti-Tamper 파일을 가져와 입력 코드 앞에 붙이던 동작을 제거했습니다.
- 오래된 AntiTamper 런타임 환경 지문 검사는 기본 프리셋에서 제외했습니다. 정상적인 런타임에서도 실패할 수 있기 때문입니다.
- 브라우저 작업 시간이 초과되면 Worker를 종료해 다음 작업에 영향을 주지 않도록 했습니다.
- 파이프라인 측정은 `os.clock()`을 우선 사용합니다.

## 웹 페이지 실행

저장소 루트에서 패키지 매니저를 설치한 뒤 다음 명령을 실행합니다.

```bash
corepack enable
pnpm install
pnpm run web:dev
```

정적 배포용 빌드:

```bash
pnpm run web:build
```

## 주의

난독화는 소스 복구를 어렵게 하는 방어층이지, 클라이언트에 전달된 코드를 완전히 비밀로 만드는 방법은 아닙니다. 실제 배포 전에는 목표 Lua/Luau 런타임에서 직접 테스트해야 합니다. 비밀키, 권한 판단, 구매 검증은 클라이언트 코드에 넣지 말고 신뢰할 수 있는 서버 측에서 처리해야 합니다.

`Strong`은 변환을 더 많이 수행하므로 `Medium`보다 실행 비용과 출력 크기가 커질 수 있습니다. 모든 입력 코드가 모든 Lua/Luau 런타임에서 자동으로 호환된다고 보장하지 않습니다.
