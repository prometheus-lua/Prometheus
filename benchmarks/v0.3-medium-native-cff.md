# Medium with native VM and Cff-protected helpers

These measurements precede the scalar assignment, cleanup, and fixed-arity VM
optimizations. See the [latest comparison](v0.3-vm-fastpaths.md).

Host: Linux-6.18.33.2-microsoft-standard-WSL2-x86_64-with-glibc2.44; CPU: 13th Gen Intel(R) Core(TM) i7-13850HX. Runtimes: Lua 5.1.5  Copyright (C) 1994-2012 Lua.org, PUC-Rio; LuaJIT 2.1.1792588164 -- Copyright (C) 2005-2026 Mike Pall. https://luajit.org/.

Four deterministic workloads compare original source with the actual presets, including AntiTamper. All variants must match the original checksum.

Seeds: [1, 4, 17]; 3 timed batches per seed. Each workload is parsed once and warmed up; batches adapt to approximately 0.1 seconds. Execution includes initialization of the emitted chunk, workload work, allocations, and checksum validation, but excludes parsing. Garbage collection runs before each batch; collection during the batch is included.

Execution figures are median CPU time per full invocation across batches and seeds. Generation and parsing figures are medians across seeds. Output size is a median across seeds. Execution ranges show the lowest and highest per-seed medians. Measurements are local, with JIT enabled for LuaJIT; very small native JIT times can produce large slowdown ratios. These workloads do not establish a general performance guarantee or measure peak memory.

## Comparison with the previous Medium

The previous figures come from the earlier local [v0.3 benchmark](v0.3-results.md).
These are separate runs on the same host; small changes can include timing
variation. Both runs used seeds 1, 4, and 17, three timed batches, and active
AntiTamper. The final pipeline preserves the VM and prototype initializers,
flattens surrounding helpers, and hoists encrypted interpreter strings into
native locals after startup decoding. Number rewriting follows Cff.

| Runtime | Workload | Previous Medium ms | Current Medium ms | Speedup |
| --- | --- | ---: | ---: | ---: |
| lua5.1 | closures | 624.017 | 415.504 | 1.50x |
| lua5.1 | numeric | 1289.751 | 1167.980 | 1.10x |
| lua5.1 | strings | 335.975 | 190.476 | 1.76x |
| lua5.1 | tables | 2166.725 | 398.476 | 5.44x |
| luajit | closures | 190.523 | 120.180 | 1.59x |
| luajit | numeric | 214.538 | 151.332 | 1.42x |
| luajit | strings | 96.007 | 52.989 | 1.81x |
| luajit | tables | 660.594 | 84.554 | 7.81x |

All 24 generated variants and 8 originals matched checksums, with 96 timed
batches. The core VM remains substantially slower than native Lua. This change
reduces the additional overhead of Medium while retaining Cff protection for
its decoder and surrounding helpers.
